Running an online store involves many repetitive tasks: reviewing orders, updating inventory, creating discounts, uploading products. Since April 2026, Shopify offers an **official connector for Claude**, Anthropic’s artificial intelligence assistant, which lets you do much of that work **by chatting**.

## What the Shopify connector for Claude is

It is an integration **built by Shopify** and verified by Anthropic, available in Claude’s connector directory. Once connected, Claude can read information from your store and, if you allow it, make changes to it.

Shopify offers similar connections for other AI tools, such as ChatGPT, Gemini, Perplexity or Microsoft Copilot, but in this article we focus on Claude.

## What it can do

According to the connector’s listing, the available tools fall into two groups:

| Read | Write |
| --- | --- |
| Store information | Create and edit products |
| Products and collections | Adjust inventory |
| Orders and customers | Create discount codes |
| Inventory levels | Create and edit collections |
| Analytics queries | Upload images |
| | Activate or deactivate products in bulk |

In addition, the Shopify Help Center states that the connector can **build a store from scratch** from a storefront preview, **source products from Shopify Collective suppliers** to import them, and **turn a file or a link into a product** ready to sell.

## Useful examples for your business

- *“What were my 10 best-selling products last month and how much did each one bring in?”*
- *“Which products have fewer than 5 units in stock?”*
- *“Create a 15% discount code for the winter collection, valid until Sunday.”*
- *“Improve the descriptions of these products so they are clearer and optimized for Google searches.”*

The advantage is that you do not need to export reports or click through several screens: you ask the question and Claude queries the data directly.

## How to connect it

1. In Claude, open the **connector directory** and search for **Shopify**.
2. Click **connect** and sign in to your store.
3. **Review and approve the permissions** it requests: what data it will be able to see and what it will be able to change.
4. Start asking questions in a new conversation.

For development teams, in April 2026 Shopify released the **Shopify AI Toolkit**, which connects tools such as Claude Code, Cursor or Visual Studio Code with Shopify’s documentation, API schemas and command line.

## Precautions before using it

- **Changes are real.** If you grant write permissions, Claude can change prices, inventory or discounts. Review what it proposes before confirming and, if possible, run your first tests on a development store.
- **Grant only the permissions you need.** If you only want reports, there is no need to authorize changes.
- **Protect your customers’ data.** Orders and customers include personal data. In Peru, processing it must comply with Law 29733 and its regulations; if in doubt, read our article on the [new data protection regulation](/en/blog/peru-data-protection-regulation-marketing).
- **Only trust official connectors.** Anthropic reminds users to only use connectors from trusted developers. Shopify’s connector is built by Shopify itself.

## In summary

The Shopify connector for Claude turns management tasks into conversations: sales, inventory, product and discount queries without leaving the chat. Set up properly, it saves hours every week. The key is to start with read permissions, review every change and protect your customers’ data.
